Unify Studio X

Status: WIP (on hold, not dead)

What is this

I started building this engine about 5 months ago. The original idea was to make a machinima tool for Roblox, something that could let people set up scenes and animate characters like a mini film studio.

Making a Roblox animation tool was something I had wanted to create for a while, mainly because I wanted more freedom than what Roblox Studio offers. I definitely underestimated how much work it would take. This was my first time trying to build an engine from the ground up, and I now understand how difficult it is to make something like this from scratch.

I couldn't finish it. I ran out of time, and some of the systems needed skills I didn't have yet at the time.

What works right now

- Renders models
- Renders environments
- Has an animation system

There isn't a tool yet that ties these together to actually produce animation with them. The pieces work on their own, but there's no workflow connecting them into a finished machinima pipeline.

What doesn't work / what's missing

- No tool yet to combine models, environment, and animation into actual scenes or animations
- Code is messy in a lot of places
- No proper project or scene management
- No UI to speak of

Why it's on hold

Not because I lost interest. I ran out of time and needed to step back. The codebase needs a cleanup pass before I can keep building on it without making things worse.

This engine DOES contain some AI-generated code. I'm not keeping it. When I return to the project, I plan to throw that code out and replace it with code I actually understand.

I don't like using AI to build my projects. From what I've seen, AI-generated code can leave behind messy implementations, hidden bugs, and things that become difficult to understand or maintain. I prefer learning things myself and using AI only when I need help understanding something.

Plans

I want to come back to this, clean up the code, remove the AI-generated parts, and start connecting the systems so it functions as a real tool instead of separate pieces. There's no timeline for this, but the project isn't abandoned.
